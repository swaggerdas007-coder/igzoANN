# Cleaned C–V (capacitance) data for the Cgd / Cgs ANNs

Generated by `scripts/clean_cv_curves.py` from the raw Keithley/B1500A C–V
exports in `data/`. Regenerate with:

```
python scripts/clean_cv_curves.py
```

These feed the two parasitic-capacitance ANNs (`src/train_cap.py`) of the
equivalent-circuit model in Bahubalindruni et al., *"InGaZnO TFT behavioral
model for IC design"*, Analog Integr Circ Sig Process (2016) 87:73–80 — the
companion elements to the drain-current ANN already trained from
`data_cleaned_2/`.

## What's here

- `cgd_clean.csv` — all retained gate–drain capacitance sweeps
- `cgs_clean.csv` — all retained gate–source capacitance sweeps
- `merged_cap_dataset.csv` — both components in one long-format table,
  columns: `cap_type, VG, VD, W, L, freq, C_F, C_pF`
- `cv_cleaning_manifest.json` — per-file QC record (kept/dropped + metrics)

Each row is one measured point of a C–VG sweep. The swept terminal voltage is
mapped to `VG` and the fixed dc bias to `VD`, so these datasets share the exact
`(VG, VD, W, L)` input interface used by the drain-current ANN
(`src/dataset.py`) — all three ANNs are pin-compatible for the Verilog-A
equivalent circuit.

## Source measurements

| Component | Files | Rows | Geometries (W–L, µm)            | Swept        | Fixed          |
|-----------|-------|------|---------------------------------|--------------|----------------|
| `cgd`     | 4     | 164  | 20-20, 40-20, 160-15, 160-20    | VG −3…5 V, 0.2 V step | VD = 0 V, f = 10 kHz |
| `cgs`     | 4     | 164  | 20-20, 40-20, 160-15, 160-20    | VG −3…5 V, 0.2 V step | VD = 0 V, f = 10 kHz |

Measured with the paper's Fig. 3 test setups: C_GD directly (dc bias on gate,
small-signal on drain), and C_GS with the drain grounding the signal. Values
are the **total** (measured) capacitances including the gate–drain/source
overlap — not the intrinsic C_GDi/C_GSi (which the paper derives by subtracting
the overlap capacitance).

## ⚠️ Baseline limitations

1. **No VD dependence.** Every individual-component sweep here was taken at a
   single drain bias (VD = 0 V, linear region). A model trained on this data
   learns `C(VG, W, L)` only and cannot reproduce the C-vs-VDS behaviour of the
   paper's Fig. 6. The VD-swept C–V files in `data/` (`C-V Vd=…`) measure the
   *total* gate capacitance Cg, which cannot be split into Cgd/Cgs without the
   Fig. 3(c) subtraction data at each VD — so they are not used here.
2. **Sparse geometry.** Only 4 devices, one instance each (L ∈ {15, 20};
   L = 15 measured only at W = 160). W/L generalisation is therefore limited.

These are the first things to fix to move past the baseline — see
`docs/CAPACITANCE_ANN.md`.
