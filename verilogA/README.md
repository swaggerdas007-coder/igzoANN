# verilogA/

Verilog-A modules generated from the trained ANNs. Weight and bias tables are
machine-written — regenerate rather than hand-edit.

| File | Contents | Generated by |
|------|----------|--------------|
| `tft_ann_full_model.va` | **Full behavioural model: ID + CGD + CGS**, one ANN per equivalent-circuit element | `scripts/export_verilog_a_full.py` |
| `tft_ann_static_deep.va` | ID only, 4→32→16→1 (the ID block used by the full model) | `scripts/export_verilog_a_deep.py` |
| `tft_ann_static.va` | ID only, single hidden layer | `scripts/export_verilog_a.py` |

## `tft_ann_full_model.va`

Implements the equivalent circuit of Bahubalindruni et al., *"InGaZnO TFT
behavioral model for IC design"*, Analog Integr Circ Sig Process (2016)
87:73–80, Fig. 1(b): each element of the EC gets its own ANN, and the ANNs are
wired together as the EC dictates.

```
                    G
                    │
         ┌──────────┼──────────┐
         │                     │
       CGD(ANN)              CGS(ANN)
         │                     │
    D ───┴───►  ID(ANN)  ──────┴─── S
```

| Element | Network | Target | Branch |
|---------|---------|--------|--------|
| ID  | 4 → 32 → 16 → 1 | log₁₀(\|ID\|), standardised | `I(D,S) <+ id` |
| CGD | 4 → 18 → 9 → 1  | C/(W·L), standardised | `I(G,D) <+ ddt(cgd·V(G,D))` |
| CGS | 4 → 20 → 10 → 1 | C/(W·L), standardised | `I(G,S) <+ ddt(cgs·V(G,S))` |

All three share the paper's Eqs. (1)–(2) form — tanh hidden layers, linear
output — and the identical 4-input interface (VG, VD, W, L) with the identical
min-max [0,1] input scaling, so the merge is a straight wiring exercise and
every element scales continuously with geometry.

The capacitances are applied as charge sources (`I <+ ddt(C·V)`) rather than
`C·ddt(V)`, so the branch currents stay charge-conserving. `gm` and `gds` are
computed analytically by differentiating the ID network through both tanh
layers.

### Instance parameters

```
parameter real w = 40e-6 from [5e-6:160e-6];   // channel width
parameter real l = 20e-6 from [5e-6:20e-6];    // channel length
```

### Caveats

- **CGD/CGS have no real VDS dependence.** VD is an input for pin-compatibility
  only; all C–V data behind those two networks was measured at VDS = 0 V. The
  paper's own CGSi/CGDi model does depend on VDS (its Figs. 5–6, CGDi → 0 in
  saturation); this module cannot reproduce that.
- **Capacitance geometry coverage is 4 (W,L) points** — (20,20), (40,20),
  (160,15), (160,20) µm — versus 19 for ID.
- Inputs are clamped to the training ranges, so the model flattens rather than
  diverging outside them.

## Verification

```
python scripts/verify_verilog_a_full.py
```

Parses the weight tables back out of the generated `.va`, re-runs the module's
exact loop arithmetic (flattened indexing, input clamping, de-standardisation,
area re-scaling) and compares against the trained PyTorch networks on every
measured operating point, then checks the EC wiring. Current status:

```
ID   32->16   max|dlog10(ID)|=7.7e-06   max rel(ID)=0.0018%   OK
CGD  18->9    max|dC|=9.3e-06 pF        max rel=0.0003%       OK
CGS  20->10   max|dC|=4.1e-06 pF        max rel=0.0007%       OK
```

Residuals are at the level of the `%.6f` weight formatting in the emitted file.
