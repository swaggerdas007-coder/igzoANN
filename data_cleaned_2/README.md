# data_cleaned_2 — one best device per geometry

A stricter cut of `data_cleaned/`: instead of keeping every device replicate
that passes QC, this folder keeps exactly **one** device per (W, L)
geometry — the single best-scoring one — for each of the three sweep kinds.

Generated by `scripts/select_best_devices.py` (built on top of
`scripts/clean_transistor_curves.py`'s QC). Regenerate with:

```
python scripts/select_best_devices.py
python scripts/plot_best_devices.py
```

## Why one device instead of several

`data_cleaned/` concatenates every device replicate that passes QC for a
given (W, L). But different replicates are different physical devices with
their own threshold-voltage/mobility variation, and the model only ever
sees `(VG, VD, W, L)` — it has no "device" input to tell them apart. Mixing
several devices' curves under one (W, L) label teaches the model
contradictory examples: the same input, different device-dependent output.
Picking a single representative device per geometry removes that
ambiguity, at the cost of throwing away the extra (correct, but
device-variable) data points `data_cleaned/` kept.

## What's here

For each of the 19 (W, L) geometries, exactly one file per sweep kind:

- `W{W}_L{L}_linear_best.csv` — Id-Vg transfer sweep, VD=0.1V
- `W{W}_L{L}_saturation_best.csv` — Id-Vg transfer sweep, VD=5V
- `W{W}_L{L}_output_best.csv` — Id-Vd output curve family

As before, `linear`/`saturation` are the forward-only VG sweep restricted
to VG in [-2, 5] (no return leg, no off-state-floor tail below -2V).

`merged_ann_dataset.csv` combines all three cleaned sweep kinds — same
columns/shape as `data_cleaned/merged_ann_dataset.csv` — but from just the
one chosen device per geometry (13,357 rows vs. `data_cleaned/`'s 39,368).

## How the best device was chosen

Only devices that already pass the `data_cleaned/` three-sweep QC (on/off
ratio, monotonic turn-on, off-state stability, VG ordering — see that
folder's README) are candidates. Among candidates for a geometry, the
winner maximizes:

```
score = sum_kind( log10(on_off_ratio_kind) ) - 2 * sum_kind(non_monotonicity_kind)
```

summed across linear, saturation and output — i.e. the cleanest on/off
separation with the least non-monotonic wiggle, averaged over all three
measurement views of that device. `best_device_manifest.json` records the
winner and every candidate's score per geometry.
